# Свой инструмент

Инструменты пользователя лежат в `tools/extensions/` рабочей папки — по файлу `.ts` на инструмент.
Они синхронизируются через GitHub, поэтому работают на всех его компьютерах.
Образец — `tools/extensions/example_tool.ts`.

## Как сделать

1. Уточни, что инструмент получает на вход и что возвращает. Спроси, как назвать (латиницей, `snake_case`).
2. Скопируй образец в `tools/extensions/<имя>.ts`, поменяй `name`, `description` (по-русски, понятно модели, когда звать), параметры и `execute`.
3. Внутри можно: `fetch` для интернета, `node:fs/promises` для файлов, `node:child_process` для команд.
   Сторонние npm-библиотеки не подключай — только встроенное в Node.
4. Скажи пользователю набрать `/reload` и проверь инструмент вызовом.
5. Объясни, что изменилось, простыми словами: что делает, как попросить.

## Правила

- Инструмент делает одно дело. Описание (`description`) — главное: по нему модель решает, когда его звать.
- Ничего не удалять в инструменте (`rm`, `unlink`) — для этого есть `file_trash`.
- Ключи и пароли в код не писать.
